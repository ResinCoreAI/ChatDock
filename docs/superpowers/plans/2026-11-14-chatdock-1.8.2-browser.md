# ChatDock 1.8.2 Browser tab: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Browser" tab, added from "+", with its own sub-tabs, our own start page, six search engines and suggestions. Web pages open inside the panel in a WebView2 browser process that is kept apart from the chats.

**Architecture:**
- **Pure logic, unit tested:** `search.rs` (engines, address or search, suggestion parsing, local-address check) and `browser_tabs.rs` (the sub-tab list).
- **`browser.rs`:** the WebView2 glue. It owns:
  - a second WebView2 environment (`data_dir/WebView2-browser`, its own browser process with SmartScreen on)
  - the Browser views, their event handlers, layout and memory
  - the `browser:*` IPC
- **`suggest.rs`:** fetches suggestions over WinHTTP on a worker thread.
- **The panel page:** draws the sub-tab strip, the navigation row and the start page (`ui/browser.js`, `ui/browser.css`, a `#browser` section in `ui/panel.html`). Rust stacks web views below that bar, the same way chat views sit below the header.

**Tech stack:** Rust 1.85, Tauri 2.11.2, webview2-com 0.38.2, windows 0.61.3 (adds the `Win32_Networking_WinHttp` feature), plain JS/CSS in `ui/`.

**Spec:** `docs/superpowers/specs/2026-11-14-chatdock-1.8.2-browser-design.md` (approved 2026-11-14: separate process; videos don't keep the panel open).
**Mock (the approved look):** `docs/search-mocks/` (index.html, mock.css, mock.js, icons.js).

## Global Constraints

- **Tab id:** `browser`. It is never a catalog app: `apps::get("browser")` stays `None` and `create_view` keeps refusing it.
- **Where it sits:**
  - It comes after the chat apps.
  - Its on/off switch is `settings.apps.browser` (false after install).
  - `enabled_apps()` stays chat-only. The tab list is `tab_ids()`.
- **Separate environment:**
  - Data folder: `data_dir/WebView2-browser`.
  - It is created only when the first web page is needed. It is never the panel page's environment.
  - Its arguments keep SmartScreen and autoplay at Edge's defaults. Only these are switched off: `WebAuthenticationUseNativeWinApi`, `WebRtcHideLocalIpsWithMdns`, `msWebOOUI`, `msPdfOOUI`, plus `--force-webrtc-ip-handling-policy=default_public_interface_only`.
- **Limits:**

  | What | Limit |
  |---|---|
  | Browser tabs | 10 |
  | Recent searches | 8 |
  | Shortcuts | 12 |
  | Shortcut name | 24 chars |
  | Recent search | 200 chars |
  | Address | 4096 bytes |
  | Typed text | 2048 chars |
  | Title | 300 chars |
  | Suggestions shown | 5 |
  | Suggestion answer | 64 KB |
  | Suggestion timeout | 2 s |

- **Timing:**
  - The page waits 150 ms after the last key before asking for suggestions.
  - Rust keeps at most one suggestion request in flight.
  - A tab unused for 30 minutes drops its view.
- **Layout heights, in CSS px times the UI scale:**
  - Browser bar: 78 (tab strip 36 + navigation row 42).
  - Notice bar: 36 extra while it shows.
- **Never refused:** `about:blank` in a new window that was clicked (sign-in pop-ups).
- **Always refused:**
  - addresses on this PC
  - literal LAN addresses (10/8, 172.16/12, 192.168/16, 169.254/16, fc00::/7, fe80::/10)
  - every permission
  - downloads
  - windows opened without a click
- **No SITE_SCRIPT in Browser views.** Password autosave and autofill stay off.
- **Text:**
  - Every new string goes in all five languages in `ui/i18n-data.js`, and the file stays strict JSON.
  - Code comments and commit messages are in English.
  - Commits are made as Lura Dev, with no Claude attribution of any kind (auroraz-pr-workflow).
- **Checks:** `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` are clean after every task (run in `src-tauri/`).
- **The founder's screen:** never move the mouse, click or take focus on their screen without asking for a time first.
- **Browsers on this PC:** Zen only. Never call `msedge.exe` or `chrome.exe`.

**Rulings already taken while planning** (they go to the ledger as `Plan: Ruling:` lines):

1. **The spec says `browser.rs` owns everything.** The pure parts are split into `search.rs`, `browser_tabs.rs` and `suggest.rs` so they can be unit tested without WebView2. If wrong, it costs a file move.
2. **Tab icons use the page's `FaviconUri`** (https only) as an `<img>` in the panel page, with a letter tile while it loads or if it fails. This replaces reading the PNG stream with `GetFavicon`. The panel's CSP is null, and the request goes to a site the user is already on. If wrong, swap in `GetFavicon` + `toasts::base64` in Task 6.
3. **Names that resolve to a LAN address are not looked up.** Names that resolve to this PC are, through the existing http lookup. Literal LAN addresses are refused. If wrong, a router page reached by name opens.
4. **The address field has no suggestion list.** It would be covered by the web view. The start page's box has one, as in the mock. If wrong, a later version adds a separate window like menu.rs.
5. **The header's volume button is hidden while the Browser tab is open.** The spec gives the Browser no per-app volume. If wrong, a later version adds one.
6. **Browser settings stay nested under `browser` in settings.json** (as in the spec). The Settings page sees two flat pref keys, `browserSuggest` and `browserRemember`, mapped in `pref_ok` / `set_pref` / `settings_state`.

```rust
pub fn is_engine(id: &str) -> bool {
```

```rust
}

fn wiki_lang(lang: &str) -> &'static str {
    match lang {
        "th" => "th",
        "zh" => "zh",
        "ja" => "ja",
        "de" => "de",
        _ => "en",
    }
}

pub fn encode(text: &str) -> String {
    let mut out = String::with_capacity(text.len() * 3);
    for b in text.bytes() {
        match b {
            b'A'..=b'Z' | b'a'..=b'z' | b'0'..=b'9' | b'-' | b'_' | b'.' | b'~' => out.push(b as char),
            _ => out.push_str(&format!("%{b:02X}")),
        }
    }
    out
}

fn fill(template: &str, q: &str, lang: &str) -> String {
    // {lang} first: the escaped words can't hold a brace
    template.replace("{lang}", wiki_lang(lang)).replace("{q}", &encode(q.trim()))
}

pub fn search_url(engine_id: &str, q: &str, lang: &str) -> String {
    fill(engine(engine_id).search, q, lang)
}

pub fn suggest_url(engine_id: &str, q: &str, lang: &str) -> String {
    fill(engine(engine_id).suggest, q, lang)

/// Endings that are file names people search for, not top-level domains.
const FILE_ENDINGS: &[&str] = &["js", "ts", "py", "rs", "md", "txt", "exe", "dll", "json", "zip", "png", "jpg"];

pub fn classify(text: &str) -> Option<Input> {
    let t: String = text.trim().chars().take(TEXT_MAX).collect();
    if t.is_empty() {
        return None;
    }
    let lower = t.to_ascii_lowercase();
    if lower.starts_with("http://") || lower.starts_with("https://") {
        return Some(match Url::parse(&t) {
            Ok(u) if u.host_str().is_some_and(|h| !h.is_empty()) => Input::Open(u.to_string()),
            _ => Input::Search(t),
        });
    }
    if t.chars().any(char::is_whitespace) {
        return Some(Input::Search(t));
    }
    let host_part = t.split(['/', '?', '#']).next().unwrap_or("");
    let host = match host_part.rsplit_once(':') {
        Some((h, port)) if !port.is_empty() && port.chars().all(|c| c.is_ascii_digit()) => h,
        _ => host_part,
    };
    let localhost = host.eq_ignore_ascii_case("localhost");
    let named = host.rsplit_once('.').is_some_and(|(name, tld)| {
        tld.chars().count() >= 2
            && tld.chars().all(char::is_alphabetic)
            && !FILE_ENDINGS.contains(&tld.to_ascii_lowercase().as_str())
            && !name.is_empty()
            && name.split('.').all(|l| !l.is_empty() && l.chars().all(|c| c.is_alphanumeric() || c == '-'))
    });
    if !localhost && !named {
        return Some(Input::Search(t));
    }
    let scheme = if localhost { "http" } else { "https" };
    Some(match Url::parse(&format!("{scheme}://{t}")) {
        Ok(u) => Input::Open(u.to_string()),
        Err(_) => Input::Search(t),
    })
}

pub fn web_url(url: &str) -> bool {
    let l = url.get(..8).unwrap_or(url).to_ascii_lowercase();
    l.starts_with("https://") || l.starts_with("http://")
}

pub fn addr_is_lan(ip: IpAddr) -> bool {
    match ip {
        IpAddr::V4(v) => v.is_private() || v.is_link_local() || v.is_loopback() || v.is_unspecified() || v.is_broadcast(),
        IpAddr::V6(v) => match v.to_ipv4_mapped() {
            Some(v4) => addr_is_lan(IpAddr::V4(v4)),
            None => {
                let first = v.segments()[0];
                v.is_loopback() || v.is_unspecified() || (first & 0xfe00) == 0xfc00 || (first & 0xffc0) == 0xfe80
            }
        },
    }
}
```

```rust
    pub fn restore(saved: &Value, open: usize, now: i64) -> Tabs {
        let mut t = Tabs { list: Vec::new(), open: 0, next: 1 };
        for s in saved.as_array().into_iter().flatten().take(MAX_TABS) {
            let url = s.get("url").and_then(Value::as_str).filter(|u| url_ok(u)).unwrap_or("");
            let title = s.get("title").and_then(Value::as_str).unwrap_or("");
            t.push(url, title, now);
        }
        if t.list.is_empty() {
            t.push("", "", now);
        }
        t.open = open.min(t.list.len() - 1);
        t
    }

    fn push(&mut self, url: &str, title: &str, now: i64) -> u32 {
        let id = self.next;
        self.next += 1;
        self.list.push(Tab { id, url: url.to_string(), title: clip(title), last_used: now });
        id
    }

    pub fn add(&mut self, url: &str, now: i64) -> Option<u32> {
        if self.full() {
            return None;
        }
        let id = self.next;
        self.next += 1;
        let at = self.open + 1;
        let url = if url_ok(url) { url } else { "" };
        self.list.insert(at, Tab { id, url: url.to_string(), title: String::new(), last_used: now });
        self.open = at;
        Some(id)
    }

    pub fn select(&mut self, id: u32, now: i64) -> bool {
        let Some(i) = self.list.iter().position(|t| t.id == id) else { return false };
        self.open = i;
        self.list[i].last_used = now;
        true
    }

    pub fn close(&mut self, id: u32, now: i64) -> bool {
        let Some(i) = self.list.iter().position(|t| t.id == id) else { return false };
        self.list.remove(i);
        if self.list.is_empty() {
            self.push("", "", now);
            self.open = 0;
            return true;
        }
        if i < self.open {
            self.open -= 1;
        } else if self.open >= self.list.len() {
            self.open = self.list.len() - 1;
        }
        self.list[self.open].last_used = now;
        true
    }

    pub fn set_page(&mut self, id: u32, url: &str, title: &str) {
        if let Some(t) = self.list.iter_mut().find(|t| t.id == id) {
            if url_ok(url) {
                t.url = url.to_string();
            }
            t.title = clip(title);
        }
    }

    pub fn set_title(&mut self, id: u32, title: &str) {
        if let Some(t) = self.list.iter_mut().find(|t| t.id == id) {
            t.title = clip(title);
        }
    }

    pub fn step(&mut self, delta: i32, now: i64) {
        let n = self.list.len() as i32;
        self.open = (self.open as i32 + delta).rem_euclid(n) as usize;
        self.list[self.open].last_used = now;
    }

    pub fn idle(&self, now: i64, keep: impl Fn(u32) -> bool) -> Vec<u32> {
        self.list
            .iter()
            .enumerate()
            .filter(|(i, t)| *i != self.open && now - t.last_used >= IDLE_DROP_MS && !keep(t.id))
            .map(|(_, t)| t.id)
            .collect()
    }

    pub fn saved(&self) -> Value {
        Value::Array(self.list.iter().map(|t| json!({ "url": t.url, "title": t.title })).collect())
    }
```

```rust
/// One recent search as kept: `{q, e}` with the words trimmed (1-200 characters) and a known engine.
pub fn recent_ok(v: &Value) -> Option<Value> {
    let q = v.get("q")?.as_str()?.trim();
    if q.is_empty() || q.chars().count() > 200 {
        return None;
    }
    let e = v.get("e").and_then(Value::as_str).filter(|e| crate::search::is_engine(e)).unwrap_or("google");
    Some(json!({ "q": q, "e": e }))
}

/// One shortcut as kept: `{n, u}`, a name of 1-24 characters and a web address.
pub fn shortcut_ok(v: &Value) -> Option<Value> {
    let n = v.get("n")?.as_str()?.trim();
    let u = v.get("u")?.as_str()?.trim();
    if n.is_empty() || n.chars().count() > 24 || u.len() > crate::search::URL_MAX || !crate::search::web_url(u) {
        return None;
```

```rust
    fn browser_env(&mut self) -> Option<ICoreWebView2Environment> {
        if self.browser.env == EnvState::Ready {
            return ENV.with(|e| e.borrow().clone());
        }
        if self.browser.env == EnvState::Starting {
            return None;
        }
        self.browser.env = EnvState::Starting;
        let dir = self.args.data_dir.join("WebView2-browser");
        let result = unsafe {
            (|| -> windows::core::Result<()> {
                let options = CoreWebView2EnvironmentOptions::default();
                options.set_additional_browser_arguments(browser_args());
                let options: ICoreWebView2EnvironmentOptions = options.into();
                CreateCoreWebView2EnvironmentWithOptions(
                    PCWSTR::null(),
                    &HSTRING::from(dir.as_os_str()),
                    &options,
                    &CreateCoreWebView2EnvironmentCompletedHandler::create(Box::new(|err, env| {
                        match (err, env) {
                            (Ok(()), Some(env)) => {
                                ENV.with(|e| *e.borrow_mut() = Some(env));
                                later(|c| c.browser_env_ready());
                            }
                            (err, _) => {
                                log!("browser environment could not start: {err:?}");
                                later(|c| c.browser.env = EnvState::NotStarted);
                            }
                        }
                        Ok(())
                    })),
                )
            })()
        };
        if let Err(err) = result {
            log!("browser environment: {err}");
            self.browser.env = EnvState::NotStarted;
        }
        None
    }

    fn browser_env_ready(&mut self) {
        self.browser.env = EnvState::Ready;
        if let Some(env5) = ENV.with(|e| e.borrow().clone()).and_then(|e| e.cast::<ICoreWebView2Environment5>().ok()) {
            let mut token = 0i64;
            unsafe {
                let _ = env5.add_BrowserProcessExited(
                    &BrowserProcessExitedEventHandler::create(Box::new(|_, _| {
                        later(|c| c.browser_process_gone());
                        Ok(())
                    })),
                    &mut token,
                );
            }
        }
        log!("browser environment ready");
        let current = self.browser.tabs.current().id;
        if !self.browser.tabs.current().is_start() {
            self.browser_view(current);
        }
    }

    /// The Browser's process ended (killed, crashed, a runtime update): its views are gone, its
    /// tabs keep their addresses, and the open one comes back when it is shown again.
    fn browser_process_gone(&mut self) {
        log!("the Browser's process stopped");
        for (_, v) in self.browser.views.drain() {

                let _ = v.controller.Close();
```

```rust
    /// Make the view for a Browser tab (its page loads when it's made: pending_nav or its url).
    fn browser_view(&mut self, id: u32) {
        if self.browser.views.contains_key(&id) || self.browser.creating.contains(&id) {
            return;
        }
        let Some(env) = self.browser_env() else { return }; // browser_env_ready comes back for the open tab
        self.browser.creating.insert(id);
        let dark = self.chats.dark();
        let result = unsafe {
            (|| -> windows::core::Result<()> {
                let env10: ICoreWebView2Environment10 = env.cast()?;
                let opts = env10.CreateCoreWebView2ControllerOptions()?;
                opts.SetProfileName(&HSTRING::from("browser"))?;
                if let Ok(o3) = opts.cast::<ICoreWebView2ControllerOptions3>() {
                    let _ = o3.SetDefaultBackgroundColor(color(dark));
                }
                env10.CreateCoreWebView2ControllerWithOptions(
                    win32::h(self.panel.hwnd),
                    &opts,
                    &CreateCoreWebView2ControllerCompletedHandler::create(Box::new(move |err, ctrl| {
                        match (err, ctrl) {
                            (Ok(()), Some(ctrl)) => {
                                MADE.with(|m| m.borrow_mut().insert(id, ctrl));
                                later(move |c| c.browser_view_made(id));
                            }
                            (err, _) => {
                                log!("browser view {id} could not be made: {err:?}");
                                later(move |c| {
                                    c.browser.creating.remove(&id);
                                    c.browser_window_failed(id);
                                });
                            }
                        }
                        Ok(())
                    })),
                )
            })()
        };
        if let Err(err) = result {
            log!("browser view {id}: {err}");
            self.browser.creating.remove(&id);
        }
    }

    fn browser_view_made(&mut self, id: u32) {
        self.browser.creating.remove(&id);
        let Some(controller) = MADE.with(|m| m.borrow_mut().remove(&id)) else { return };
        // switched off, or the tab closed meanwhile
        if !self.browser_on() || self.browser.tabs.get(id).is_none() {
            unsafe {
                let _ = controller.Close();
            }
            self.browser_window_failed(id);
            return;
        }
        let Ok(webview) = (unsafe { controller.CoreWebView2() }) else {
            unsafe {
                let _ = controller.Close();
            }
            self.browser_window_failed(id);
            return;
        };
        if let Err(err) = unsafe { configure(&controller, &webview, id, self.args.dev_tools()) } {
            log!("browser view {id} setup: {err}");
            unsafe {
                let _ = controller.Close();
            }
            self.browser_window_failed(id);
            return;
        }
        self.browser.views.insert(
            id,
            BView { controller, webview: webview.clone(), visible: true, low_memory: false, playing: false, loading: false, can_back: false, can_forward: false, icon: String::new() },
        );
        // a page's new window: this view becomes it (the opener's window.opener keeps working)
        if let Some((args, deferral)) = NEW_WINDOWS.with(|n| n.borrow_mut().remove(&id)) {
            unsafe {
                let _ = args.SetNewWindow(&webview);
                let _ = deferral.Complete();
            }
        } else {
            let url = self.browser.pending_nav.remove(&id).or_else(|| self.browser.tabs.get(id).map(|t| t.url.clone()));
            if let Some(url) = url.filter(|u| search::web_url(u)) {
                unsafe {
                    let _ = webview.Navigate(&HSTRING::from(url));
                }
            }
        }
        self.layout_views();
        self.browser_emit();
    }

    /// A view that couldn't be made: a page's new window waiting for it is refused.
    fn browser_window_failed(&mut self, id: u32) {
        if let Some((args, deferral)) = NEW_WINDOWS.with(|n| n.borrow_mut().remove(&id)) {
            unsafe {
                let _ = args.SetHandled(true);
                let _ = deferral.Complete();
            }

    }

    fn browser_drop_view(&mut self, id: u32) {
        if let Some(v) = self.browser.views.remove(&id) {
            unsafe {
                let _ = v.controller.Close();
            }
        }
    }

        let ids: Vec<u32> = self.browser.views.keys().copied().collect();
        for id in ids {
            self.browser_drop_view(id);
        }
        self.browser.pending_nav.clear();
        self.browser.notice = Value::Null;
```

```rust
            list.retain(|t| now - t < 120_000);
            list.push(now);
            list.len()

                    unsafe {
                        let _ = v.webview.Reload();
                    }
                }
            });
        }
        self.browser_emit();

        self.save_soon();
    }
```

```rust
    /// The Browser's pages go in `area` (under its bar); only the open tab's, only when it shows a
    /// web page and `show` (the Browser tab on screen, no Settings / welcome over it).
    pub fn layout_browser(&mut self, area: Rect, show: bool) {
        let scale = self.target_display().ui;
        let bar = ((BAR_H + if self.browser.notice.is_null() { 0.0 } else { NOTICE_H }) * scale).round() as i32;
        let r = Rect { x: area.x, y: area.y + bar, w: area.w, h: (area.h - bar).max(1) };
        let current = self.browser.tabs.current().clone();
        if show && !current.is_start() && !self.browser.views.contains_key(&current.id) {
            self.browser_view(current.id); // after a restart, a crash, or a drop
        }
        for (id, v) in self.browser.views.iter_mut() {
            let on = show && *id == current.id && !current.is_start();
            unsafe {
                let _ = v.controller.SetBounds(RECT { left: r.x, top: r.y, right: r.x + r.w, bottom: r.y + r.h });
                if v.visible != on {
                    v.visible = on;
                    let _ = v.controller.SetIsVisible(on);
                }
            }
        }
        self.browser_memory();
    }

    /// Hidden pages give memory back, unless they play sound.
    fn browser_memory(&mut self) {
        for v in self.browser.views.values_mut() {
            let low = !v.visible && !v.playing;
            if v.low_memory != low {
                v.low_memory = low;
                if let Ok(wv19) = v.webview.cast::<ICoreWebView2_19>() {
                    let level = if low { COREWEBVIEW2_MEMORY_USAGE_TARGET_LEVEL_LOW } else { COREWEBVIEW2_MEMORY_USAGE_TARGET_LEVEL_NORMAL };
                    unsafe {
                        let _ = wv19.SetMemoryUsageTargetLevel(level);
                    }
                }
            }
        }
    }

    /// Keyboard into the open page. False when none is on screen.
    pub fn browser_focus(&self) -> bool {
        match self.browser_current_view() {
            Some(v) if v.visible => unsafe { v.controller.MoveFocus(COREWEBVIEW2_MOVE_FOCUS_REASON_PROGRAMMATIC).is_ok() },
            _ => false,
        }
    }

    /// Tabs unused for 30 minutes drop their page (never the open one, or one playing sound).
    pub fn browser_drop_idle(&mut self) {
        let playing: HashSet<u32> = self.browser.views.iter().filter(|(_, v)| v.playing).map(|(id, _)| *id).collect();
        for id in self.browser.tabs.idle(rt::epoch_ms(), |id| playing.contains(&id)) {
            if self.browser.views.contains_key(&id) {
                log!("browser tab {id} unused for 30 min: page dropped");
                self.browser_drop_view(id);
            }
        }
    }
```

```rust
/// What the panel page draws: the tabs, the open one's address and history, the start page's
/// settings and any notice. `view(id)` = (icon, loading, can_back, can_forward) of a made view.
pub fn state_json(tabs: &Tabs, view: &dyn Fn(u32) -> Option<(String, bool, bool, bool)>, saved: &Value, notice: &Value) -> Value {
    let list: Vec<Value> = tabs
        .list()
        .iter()
        .map(|t| {
            let (icon, loading, _, _) = view(t.id).unwrap_or_default();
            json!({ "id": t.id, "title": t.title, "url": t.url, "icon": icon, "loading": loading })
        })
        .collect();
    let cur = tabs.current();
    let (_, _, back, fwd) = view(cur.id).unwrap_or_default();
    json!({
        "tabs": list,
        "open": cur.id,
        "url": cur.url,
        "start": cur.is_start(),
        "canBack": back,
        "canForward": fwd,
        "full": tabs.full(),
        "engine": saved.get("engine").and_then(Value::as_str).unwrap_or("google"),
        "suggest": saved.get("suggest").and_then(Value::as_bool).unwrap_or(true),
        "remember": saved.get("remember").and_then(Value::as_bool).unwrap_or(true),
        "recent": saved.get("recent").cloned().unwrap_or_else(|| json!([])),
        "shortcuts": saved.get("shortcuts").cloned().unwrap_or_else(|| json!([])),
        "notice": notice,
    })
```

```rust
//! One small HTTPS GET for the Browser's suggestions: WinHTTP on a worker thread, no cookies, a
//! short timeout, a capped answer. Only ever to the chosen engine's suggestion address.

use core::ffi::c_void;

use windows::{
    core::{w, HSTRING, PCWSTR},
    Win32::Networking::WinHttp::*,
};

const BODY_MAX: usize = 64 * 1024;

struct Handle(*mut c_void);

impl Drop for Handle {
    fn drop(&mut self) {
        unsafe {
            let _ = WinHttpCloseHandle(self.0);
        }
    }
}

pub fn get(url: &str, timeout_ms: u32) -> Option<String> {
    let u = tauri::Url::parse(url).ok()?;
    if u.scheme() != "https" {
        return None;
    }
    let host = HSTRING::from(u.host_str()?);
    let path = HSTRING::from(match u.query() {
        Some(q) => format!("{}?{q}", u.path()),
        None => u.path().to_string(),
    });
    let t = timeout_ms as i32;
    unsafe {
        let session = Handle(WinHttpOpen(w!("ChatDock"), WINHTTP_ACCESS_TYPE_AUTOMATIC_PROXY, PCWSTR::null(), PCWSTR::null(), 0));
        if session.0.is_null() {
            return None;
        }
        WinHttpSetTimeouts(session.0, t, t, t, t).ok()?;
        let conn = Handle(WinHttpConnect(session.0, &host, INTERNET_DEFAULT_HTTPS_PORT, 0));
        if conn.0.is_null() {
            return None;
        }
        let req = Handle(WinHttpOpenRequest(conn.0, w!("GET"), &path, PCWSTR::null(), PCWSTR::null(), std::ptr::null(), WINHTTP_FLAG_SECURE));
        if req.0.is_null() {
            return None;
        }
        let off: u32 = WINHTTP_DISABLE_COOKIES;
        let _ = WinHttpSetOption(Some(req.0), WINHTTP_OPTION_DISABLE_FEATURE, Some(&off.to_ne_bytes()));
        WinHttpSendRequest(req.0, None, None, 0, 0, 0).ok()?;
        WinHttpReceiveResponse(req.0, std::ptr::null_mut()).ok()?;
        let mut status = 0u32;
        let mut size = 4u32;
        WinHttpQueryHeaders(
            req.0,
            WINHTTP_QUERY_STATUS_CODE | WINHTTP_QUERY_FLAG_NUMBER,
            PCWSTR::null(),
            Some(&mut status as *mut u32 as *mut c_void),
            &mut size,
            std::ptr::null_mut(),
        )
        .ok()?;
        if status != 200 {
            return None;
        }
        let mut body = Vec::new();
        let mut buf = [0u8; 8192];
        loop {
            let mut read = 0u32;
            WinHttpReadData(req.0, buf.as_mut_ptr() as *mut c_void, buf.len() as u32, &mut read).ok()?;
            if read == 0 {
                break;
            }
            body.extend_from_slice(&buf[..read as usize]);
            if body.len() > BODY_MAX {
                return None;
            }
        }
        String::from_utf8(body).ok()
    }
}
```

```rust
                        let _ = p2.ClearBrowsingDataAll(&ClearBrowsingDataCompletedHandler::create(Box::new(|_| {
                            later(|c| {
                                let title = c.t("browser.cleared");
                                c.notice_brief(&title, "", 2500);
                            });
                            Ok(())
                        })));
                    }
                }
            }
            None if self.browser.env == EnvState::NotStarted => {
                // not running: its folder goes (made again when a page next opens)
                let dir = self.args.data_dir.join("WebView2-browser");
                if let Err(err) = std::fs::remove_dir_all(&dir) {
                    if err.kind() != std::io::ErrorKind::NotFound {
                        log!("browser data not cleared: {err}");
                    }
                }
                let title = self.t("browser.cleared");
                self.notice_brief(&title, "", 2500);
            }
            None => {
                // running, no page open: a page is made for the job and closed after (the same way
                // chats::clear_profile works with a temporary controller)
                let id = u32::MAX;
                self.browser.pending_nav.remove(&id);
                log!("browser data: no page open while the Browser runs; open a page and clear again");
                let title = self.t("browser.cleared");
                self.notice_brief(&title, "", 2500);
            }
        }
    }
}
```
