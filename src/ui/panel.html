ChatDock

แชท IG · Facebook · X · Discord ข้างจอ ไม่ต้องสลับหน้าต่าง

  1. เปิดแชท — ชี้เมาส์ไปที่ขอบขวาของจอ แถบสีขาวจะโผล่ออกมา แล้วคลิก คลิกไอคอนแอปบนแถบ เพื่อเปิดแอปนั้นได้ทันที · ย้ายไปขอบซ้ายได้ในตั้งค่า
  2. ปุ่มลัด — กด ได้ทุกที่ แม้กำลังเล่นเกม
  3. ซ่อน — คลิกที่อื่น, กดปุ่มลัดซ้ำ หรือกด Esc 2 ครั้ง ระบบจะพากลับไปที่เกม/โปรแกรมเดิมให้เอง ไม่ต้องคลิกเกมซ้ำ
  4. ปักหมุด ถ้าอยากให้แชทค้างไว้ · Ctrl+1, Ctrl+2, … สลับแอป
💬 มีคนทักมา → ป๊อปอัพเด้งที่มุมจอ ลอยทับเกมได้ บอกว่าใครทักและพิมพ์ว่าอะไร · คลิกเพื่อเปิดแชทนั้นเลย
🔴 ยังไม่ได้อ่าน จะมีแถบไฟเล็กๆ ติดที่ขอบจอ และไอคอนในถาดมีจุดแดง

⚙️ เลือกแอป (มี Telegram, WhatsApp ด้วย), ย้ายซ้าย/ขวา, ตั้งป๊อปอัพ, ปุ่มลัด ฯลฯ ได้ที่ปุ่ม ด้านบน หรือคลิกขวาไอคอน ChatDock ที่ถาดมุมขวาล่าง

ห้ามรบกวนปิดอยู่
เงียบตอนเกม/วิดีโอเต็มจอไม่เด้งเมื่อหน้าต่างที่ใช้อยู่เต็มจอ
ตำแหน่งป๊อปอัพถ้าแชทเปิดอยู่ฝั่งเดียวกัน ป๊อปอัพจะหลบไปข้างๆ ให้เอง
แสดงนานชี้เมาส์ค้างไว้บนป๊อปอัพ = หยุดนับเวลา
แสดงพร้อมกันได้สูงสุดที่เหลือรวมเป็น “+ อีก N ข้อความ”
แสดงข้อความที่ทักมาปิด = บอกแค่ว่าใครทัก (กันคนข้างๆ แอบอ่าน)
แสดงรูปโปรไฟล์คนทัก

ลองดูหน้าตา

ความปลอดภัยและความเป็นส่วนตัว

  • ล็อกอินกับหน้าเว็บจริงของแต่ละแอปโดยตรง — ChatDock ไม่เห็นและไม่เก็บรหัสผ่าน
  • แต่ละแอปแยกที่เก็บคุกกี้ของตัวเอง แอปหนึ่งอ่านข้อมูลของอีกแอปไม่ได้
  • หน้าแชททำงานใน sandbox: แตะไฟล์หรือโปรแกรมในเครื่องไม่ได้ และคุยกับโปรแกรมในเครื่องผ่าน localhost ไม่ได้
  • ลิงก์ที่ออกนอกแอปเปิดในเบราว์เซอร์ปกติของคุณ · ปิดหน้าต่าง passkey ของ Windows ที่เว็บชอบเด้งเอง
  • ไฟล์โปรแกรมถูกล็อก: ถ้ามีใครแก้ไฟล์ของ ChatDock โปรแกรมจะไม่ยอมเปิด และปิดช่องทางสั่งรันโค้ดแปลกปลอม (RunAsNode, NODE_OPTIONS, --inspect)
  • อัปเดตดาวน์โหลดผ่าน HTTPS จาก GitHub ของโปรเจกต์ และตรวจ SHA-512 ก่อนติดตั้งทุกครั้ง
ซ่อนจากการแคปจอ/สตรีมแชทและป๊อปอัพจะไม่ติดในรูปแคปจอ, OBS, Discord stream
ออกจากระบบทุกแอปลบคุกกี้ การล็อกอิน และแคชของทุกแอปในเครื่องนี้
